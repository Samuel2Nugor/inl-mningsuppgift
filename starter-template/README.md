# Starter Template – IoT Telemetry & Analytics Platform

Detta är startmallen för inlämningsuppgiften i *Dataplattformar, dataintegration och molnlösningar*.

## Kom igång

1. Studera instruktionerna i `../Inlämningsuppgift.md`.
2. Bygg och färdigställ koden i `api/app.py`, `openapi.yaml`, `api/Dockerfile` samt `docker-compose.yml`.
3. Starta applikationen:
   ```bash
   docker-compose up --build
   ```
4. Verifiera kontraktet med Schemathesis:
   ```bash
   docker-compose run tests
   ```
